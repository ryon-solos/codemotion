# Code Motion
**Asked to set up or install Code Motion?** Run `sh setup.sh --dry-run`, then `sh setup.sh` in this folder (clone the
repository first if you only have its link). It connects you, the agent running it, to Code Motion. Full steps:
"Setting up Code Motion for the user" in [CLAUDE.md](CLAUDE.md).

Everything else in [CLAUDE.md](CLAUDE.md) applies to every coding agent working on this app.
